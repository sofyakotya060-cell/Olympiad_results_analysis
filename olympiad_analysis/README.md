# анализ результатов онлайн-олимпиады

этот проект посвящен комплексному анализу результатов онлайн-олимпиады для школьников. главная цель — превратить «сырую» таблицу с результатами в понятную аналитику, найти аномалии и подготовить выводы, полезные продуктовой и образовательной командам.

## цель и задачи
в рамках проекта было выполнено три основных блока работы:
1. **предобработка:** очистка данных от дубликатов, исправление опечаток в названиях регионов, обработка пропусков и расчет новых метрик (например, длительность сессии).
2. **аналитика (python + sql):** написание sql-запросов для агрегации данных по регионам, классам и устройствам, а также проверка статистических гипотез.
3. **визуализация и выводы:** построение графиков для оценки сложности заданий и поведения участников, формулировка бизнес-инсайтов.

## стек технологий
*   **язык:** python 3
*   **обработка данных:** pandas, numpy
*   **работа с базой данных:** sqlite3 (sql)
*   **статистика:** scipy.stats
*   **визуализация:** matplotlib, seaborn
*   **среда:** jupyter notebook
